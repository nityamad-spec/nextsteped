# Career Readiness interview-round color treatment

## Direction
Use a restrained, monochromatic indigo treatment that fits the existing product palette. Explore a horizontal four-card layout while keeping all existing content exactly as-is.

## Changes
- Give the full “The rounds you'll face” section a very light indigo background to distinguish it from the surrounding white sections.
- Arrange the four rounds as an equal-width horizontal row on desktop, progressing visually from round 1 to round 4.
- Apply four distinct solid indigo tints to the round cards, progressing from lightest on round 1 to darkest on round 4.
- Adjust each card’s border, number badge, weight badge, and text contrast to remain readable as the tint deepens.
- Preserve every existing round title, description, order, and weight percentage without rewriting or adding content.
- Stack the cards vertically on smaller screens so the full descriptions remain readable without horizontal page scrolling.
- Keep the surrounding section structure and behavior unchanged.
- Define the progression through semantic design tokens for consistent light and dark themes.

## Verification
- Check the Understand view on desktop and mobile to confirm the horizontal layout, responsive stack, and color progression feel balanced.
- Confirm all four descriptions and weight percentages match the current content and remain easy to read.
- Confirm dark mode contrast remains accessible.
